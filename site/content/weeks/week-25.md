# Week 25: Open-source PR #2

**12–18 April 2027 · Block D · Outline**

## Why this week exists

Your first PR showed you can contribute. This one should show **domain depth** in a project close to the job you want. After weeks 18–24 you know MIDI import, notation models, onset detection and pitch tracking better than most contributors to these projects do. Use that.

## Targets (choose by what you can contribute from Block D)

- **MuseScore**: [good first issues](https://github.com/musescore/MuseScore/issues?q=is%3Aopen+label%3A%22good+first+issue%22); the MIDI import code you read in week 22; [CONTRIBUTING](https://github.com/musescore/MuseScore/blob/master/CONTRIBUTING.md). C++/Qt, with a large build: start the build on day 1.
- **aubio**: [repo](https://github.com/aubio/aubio); pitch and onset code you've read (weeks 4, 10). C.
- **Audacity**: [issues](https://github.com/audacity/audacity/issues). C++, and Muse Group (it's theirs).
- **OpenSheetMusicDisplay**: [issues](https://github.com/opensheetmusicdisplay/opensheetmusicdisplay/issues). TypeScript, MusicXML rendering.

Same process as week 16: comment first, small and focused, tests, their conventions, fast and polite responses to review. If week 16's PR is still unmerged, finish that first ([Rules §3](#/rules): no skipping gates).

## Gate

- **w25.pr:** a merged PR in MuseScore, aubio, Audacity, OSMD or another notation/MIR project. If review is slow, the gate stays open, and the late status is logged honestly.
