# Foundations (Band A)

**Chosen on 25 October 2026.** Four weeks, F1–F4 (26 October – 22 November 2026), before Week 1 (which now starts 23 November). Same hours (15+ a week), same rules, and **no AI at all**.

A low or self-assessed "rusty" starting point usually means one thing: you've been *directing* code rather than *writing* it, and the muscles that read and trace code haven't been trained. These four weeks train them on small programs and on real OnStand functions, so you don't learn the basics and OnStand's complexity at the same time.

| Week | Focus | Exit evidence |
|---|---|---|
| [F1: Tracing programs by hand](#/week/F1) | The baseline (diagnostic B + E); predict-then-run; variable tables | ≥ 9 of the last 10 predictions right |
| [F2: Functions, closures and the event loop](#/week/F2) | Closures, `debounce`, the event loop, why the metronome needs the audio clock | Event-loop recording |
| [F3: Reading and writing TypeScript](#/week/F3) | Types, narrowing, `Result`, exhaustive switches, dependency injection | `tsc --strict` clean |
| [F4: Git, testing, and the re-take](#/week/F4) | Terminal git, writing tests, the sealed re-take | **B′ + E′ ≥ 24 / 40** |

**The exit rule:** Week 1 starts only after the F4 re-take reaches 24/40. If it doesn't, F3–F4 repeat with new material, and the plan moves by two weeks in a `replan:` commit. Foundations is a ramp, not a place to stay.

**Every Foundations week also includes:** DSA (3–4 problems, a 35-minute timer each), a predict-then-run log, an Anki deck, retrieval questions and a no-notes recording, so the habits of Weeks 1–36 start now.
